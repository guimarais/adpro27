## Why

Students have a small reproducible Python project but need to change it with others and demonstrate that behavior still works. Class 03 must begin with Git basics, connect branches and review to meaningful pytest checks, and preserve the ordered, independently executable VS Code lesson format.

## What Changes

- Author five ordered notebooks, `03.1`–`03.5`, covering Git basics, collaboration, behavior tests, fixtures/parametrization, and review/conflict practice.
- Supply local Git starter files, recorded status/diff examples, a review patch, a conflict example, a working Report package, and a passing pytest suite.
- Keep Git mutation, credentials, push, and pull-request actions as explicit student steps in separate practice repositories. Default notebook execution and references never operate on the course repository or contact GitHub.
- Provide six exercise chains with independent `.py` references and commented `%load` cells.
- Add a Creative Commons image-suggestion guide with verified file-page licenses, authors, attribution text, and teaching placements.
- Verify isolated Git workflows, test behavior and seeded failures, fresh notebook execution, budgets, references, and static presentation.

## Capabilities

### New Capabilities

- `class-03-content`: Ordered Git/collaboration/pytest teaching materials with local practice and attributed illustration suggestions.

### Modified Capabilities

None in the accepted main spec tree. Reuse the existing unarchived template and earlier-class implementations, extending their shared verifier for class 03.

## Impact

Adds `classes/03-git-collaboration-and-testing/`, its environment, exercises, source/tests, and instructor/image guides. Updates course navigation and shared checking. It does not modify the real repository history, publish pull requests, redesign assessment, or require paid services.
