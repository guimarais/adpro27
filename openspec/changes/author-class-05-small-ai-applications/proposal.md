## Why

Students need to understand the application code around a model without writing an
orchestration system. The approved Class 05 interview limits student edits to tiny
single-line completions and focuses learning on glossary-backed explanations,
observable traces, deterministic checks, and a five-prompt evaluation.

## What Changes

- Add five standalone ordered notebooks, six explained references, a progressive
  glossary, a class workspace, and a locked local uv environment.
- Supply a two-tool read-only application over the active class-04 population
  snapshot, preserving Observation(label, value) and deterministic summary behavior.
- Supply strict argument/final-answer validation, an explicit allowlist, a bounded
  loop, fixed illustrative replays, and explicit direct OpenAI SDK execution.
- Keep required work offline and credential-free; live OpenAI and CPU Ollama
  remain explicitly separate paths with honest evidence limits.
- Preserve 90 classroom/210 independent minutes and the optional 180-minute ceiling.
- Update curriculum, authoring/verifier integration, and execution records.

## Capabilities

### New Capabilities

- `class-05-content`: Very small AI application teaching with supplied orchestration,
  progressive vocabulary, validated tools, bounded execution, and evaluation evidence.

### Modified Capabilities

None in the main spec tree. Extend existing course authoring/verifier conventions
without changing earlier class contracts.

## Impact

Adds the Class 05 distribution and specification. No new assessment policy, UI,
deployment, paid-service requirement, model download, legacy-tree tracking, or
publication is introduced. Live access, desktop behavior, local CPU performance,
and beginner timings require their own delivery evidence.
